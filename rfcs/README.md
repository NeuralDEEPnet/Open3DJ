# RFCs

Written proposals for big changes: the public agent contract and file formats, the script language, new runtime dependencies with license obligations, the security model, and the governance documents. [GOVERNANCE.md](../GOVERNANCE.md#big-changes-rfcs) says when an RFC is needed and how a decision is made; [CONTRIBUTING.md](../CONTRIBUTING.md#rfcs-for-big-changes) is the short version.

Start from [0000-template.md](0000-template.md). Open an issue labeled `rfc` first, then add the write-up here in a pull request. The pull request stays open while the RFC is discussed, and merges only when the RFC is accepted, so every file in this folder is an accepted RFC.

| RFC | Title | Status |
|---|---|---|
| 0001 | Prompt Open3DJ from the viewer page (the agent panel) | under discussion in #31 |

Experiments do not need an RFC. Their write-ups go in `rfcs/experiments/`, tracked with the `experiment` label.
