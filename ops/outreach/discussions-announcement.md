**Title:** `Help test Open3DJ on your machine`

**Body:**

````markdown
Open3DJ, the open-source and agent-first CAD project created by Neural Deep Network LTD, now installs with one command on Windows, macOS and Linux. Before we go further, we need to know that it works on real machines, and that is where you come in.

**Where things stand.** The full test suite runs in CI on Windows x64 and ARM64, macOS on Apple Silicon, and Linux x64 and ARM64. But nobody outside the project has installed Open3DJ on their own computer yet, and the browser viewer has never been checked on a real GPU.

**What we ask.** About 15 minutes:

1. Install with the one-line command for your system: [docs/TESTING.md](https://github.com/NeuralDEEPnet/Open3DJ/blob/main/docs/TESTING.md#install).
2. Run the [checklist](https://github.com/NeuralDEEPnet/Open3DJ/blob/main/docs/TESTING.md#the-15-minute-checklist): `open3dj doctor --report`, three examples, the 3D viewer with live reload, and a STEP export opened in the CAD tool you already use.
3. File a [hardware report](https://github.com/NeuralDEEPnet/Open3DJ/issues/new?template=hardware_report.yml), even if everything worked.

**Especially wanted:** Windows 10 and 11, Windows on ARM, Intel Macs, Linux distributions other than Ubuntu, WSL2, Raspberry Pi 5 and other ARM boards, Chromebooks, and any real GPU from NVIDIA, AMD, Intel, Apple or Qualcomm.

**Extras, if you have time:** print the bracket example and measure it, or connect Claude Desktop, Claude Code, Codex, Cursor, VS Code or Gemini CLI and ask your agent to design a small part. Share prints and parts in Show and tell.

**Credit.** Every tester who wants it is added to [CONTRIBUTORS.md](https://github.com/NeuralDEEPnet/Open3DJ/blob/main/CONTRIBUTORS.md) and named in the release notes.

Questions about installing or testing are welcome in Q&A. Thank you for helping.

Generated by [neuraldeep.net design agents](https://www.neuraldeep.net)
````
