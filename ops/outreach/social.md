## LinkedIn

```text
We are looking for people to test Open3DJ on their own computers.

Open3DJ is an open-source (MIT) CAD project created by Neural Deep Network LTD. It does exact parametric solid modeling, the B-rep geometry that engineering and manufacturing rely on, and it is built so that AI agents can drive it over the Model Context Protocol and check their own work. Every change returns evidence: validity, volume, bounding box, clash and clearance checks, and a four-view drawing. It exports STEP, STL, GLB and 3MF, and it runs locally.

It is early. There is a command line, an MCP server and a browser viewer, but no desktop app yet. The test suite runs in CI on Windows, macOS and Linux, on x64 and ARM, but nobody outside the project has run it on a real machine.

That is the ask. If you have 15 minutes and a Windows PC, a Mac, a Linux machine, a Raspberry Pi or a workstation with a real GPU, the tester guide installs Open3DJ with one command and walks you through a short checklist: run a few examples, look at a model in the browser, and open an exported STEP file in the CAD tool you already use. Then you file a short report.

Engineers, designers, makers and anyone who uses CAD are welcome. No programming experience is needed. Every tester who wants it is credited in the repository and in the release notes.

Tester guide: https://github.com/NeuralDEEPnet/Open3DJ/blob/main/docs/TESTING.md
Repository: https://github.com/NeuralDEEPnet/Open3DJ
```
