Open3DJ is open-source, agent-first CAD created by [Neural Deep Network LTD](https://www.neuraldeep.net). It runs on your own computer: AI agents drive it over MCP, and people use the command line and a 3D viewer in the browser. It is early. There is no desktop app yet, and nobody outside the project has run it on a real machine.

**We need your machine.** Our automatic checks pass the full test suite on five cloud machines (Windows x64 and ARM64, macOS on Apple Silicon, Linux x64 and ARM64), but cloud machines have no GPU, no antivirus, no company proxy and no unusual setups. Only real machines can tell us whether Open3DJ works for real people.

## How to help (about 15 minutes)

1. Install Open3DJ with one command. Follow [docs/TESTING.md](https://github.com/NeuralDEEPnet/Open3DJ/blob/main/docs/TESTING.md#install). No git or Node.js experience needed.
2. Run the [15-minute checklist](https://github.com/NeuralDEEPnet/Open3DJ/blob/main/docs/TESTING.md#the-15-minute-checklist): describe your machine with `open3dj doctor --report`, run three examples, look at an enclosure in the browser viewer, and open an exported STEP file in another CAD tool. Printing a part and connecting an AI agent are optional extras.
3. File a [hardware report](https://github.com/NeuralDEEPnet/Open3DJ/issues/new?template=hardware_report.yml). A report that says "everything worked" is just as useful as one that found a problem. For anything broken, also file a [failure report](https://github.com/NeuralDEEPnet/Open3DJ/issues/new?template=failure_report.yml).
