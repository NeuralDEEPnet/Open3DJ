## Notes for Claude Code

- **Use plan mode for multi-file changes.** Present the plan, including which files change and why, and wait for the operator's approval before editing.
- **Prefer subagents for research.** Use them to read sources and check claims in parallel, and bring back only the findings with their links.
- **Keep commits small.** One logical change per commit, without `-s`; the operator signs off after review, and only when the operator asks you to commit.
- **Use the project attribution.** When working for Neural Deep Network LTD, end commit messages with `Assisted-by: neuraldeep.net design agents`, and end pull request descriptions and GitHub comments with `Generated by [neuraldeep.net design agents](https://www.neuraldeep.net)`. Do not add model names or model identifiers. See [Attribution for Neural Deep Network agents](CONTRIBUTING.md#attribution-for-neural-deep-network-agents).
- **Never echo secrets.** Do not print, log or paste tokens or keys from the environment into files, commits, comments or tool output.
